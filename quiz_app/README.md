# Trivia Quiz App

A responsive, interactive frontend quiz application built with vanilla JavaScript, CSS3, and HTML5 that fetches real-time multiple-choice trivia questions from the Open Trivia Database API.

## Live Demo
- [Live Demo on GitHub Pages](https://akash1co.github.io/week-2-tasks/quiz_app/)

## Features
- Dynamic API data consumption using `fetch()` and `async/await`.
- Responsive layout designed for desktop and mobile viewports.
- Real-time score calculation with immediate visual feedback.
- Accessible DOM manipulation for rendering questions and answers.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Media Queries)
- JavaScript (Fetch API, DOM manipulation, Async/Await)
- Open Trivia API
